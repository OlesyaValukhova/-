# Navigator: полный наблюдаемый аналитический слой

Дата: 11.11.2026. Быстрый офлайн-аудит охватывает все 43 250 сохранённых
детальных карточек из снимка Navigator.

| Поле / пересечение полей | Карточек | Доля от 43 250 |
|---|---:|---:|
| ID и название | 43 250 | 100,0% |
| Непустой опубликованный адрес | 37 708 | 87,2% |
| Валидная опубликованная координата | 17 684 | 40,9% |
| Полный числовой возрастной интервал карточки | 37 364 | 86,4% |
| ID + название + координата + возраст | **16 067** | **37,1%** |

Последняя строка — доступное для пространственно-возрастного анализа
подмножество каталога. После дедупликации одинаковых опубликованных пар
долгота/широта (12 знаков после запятой) остаётся **1 743 уникальные
координаты площадок-прокси**. Для возраста 7 лет в этом подмножестве допустимы
7 062 карточки, для 13 лет — 7 463.

Основной B1 будет считать `N_venue`: число уникальных опубликованных
координат в сетевом пороге. Дополнительный `N_offer_card` — число карточек на
этих координатах; он не интерпретируется как число подтверждённых мест занятий.

Отсутствующие у 62,9% карточек координата и/или возраст не означают отсутствия
предложения. Поэтому итог формулируется только для «доступного для анализа
подмножества каталога». Координата карточки не подтверждает место конкретной
группы, вход, расписание, вместимость или фактическое посещение.
