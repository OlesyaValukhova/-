# Возрастные профили B1 по кварталам BlocksNet

Готовые по-точечные результаты B1 агрегированы к 3 330 кварталам BlocksNet для 43 направлений. Маршрутизация не повторялась. Единица назначения — уникальная опубликованная координата карточки внутри направления; не подтверждённая площадка и не место в группе.

Для каждого квартала: число жилых точек, валидных точек и точек без покрытия; доли состояний «оба возраста», «только 7», «только 13», «ни для одного» среди валидных; медианы N7, N13, N13−N7 и, при наличии обеих конечных величин, t13−t7. Кварталы с менее чем тремя валидными точками не показаны на PNG-картах.

Проверки: `origin_id` уникален в исходных слоях; 30 224 из 30 611 точек подключены к сети, 387 учтены отдельно; суммы четырёх долей равны 100% для всех кварталов с валидными точками. Нет кластеризации или присвоения типов кварталам.

Файлы: `age_profiles_by_block.csv`, `age_profiles_blocks.gpkg` (слой `profiles`), `maps/`, `manifest.json`.

Результат описывает потенциальную достижимость наблюдаемого предложения в B1, а не фактическую мобильность, безопасность, сопровождение, спрос, вместимость или соответствие СП 460.
