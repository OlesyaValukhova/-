# Презентация НИР v35

**Рабочая ветка:** `codex/presentation-b1-v35`  
**Основа:** v34, без перезаписи предыдущих версий.  
**Сценарий:** B1, пешком, 30 минут; возрастные срезы 7 и 13 лет.  
**Объём:** 20 слайдов, 20 пунктов речи.

## Что изменено
- Четыре квартальные карты программирования и ИЗО пересобраны в SVG из фактической геометрии BlocksNet и таблиц `b1_81.csv` / `b1_38.csv`.
- График 43 направлений также пересобран в SVG из `b1-direction-summary.csv`; он показывает разницу долей точек с ≥1 координатой (13 лет минус 7 лет) в процентных пунктах.
- Добавлена пятая карта — доля жилых точек без сетевого покрытия по кварталам. Это диагностическая карта привязки исходных точек, а не карта доступности занятий.
- Все карты имеют один экстент, масштаб, EPSG:32636, формат 16:9, белый фон и общую палитру.
- В легендах раздельно показаны 1–2 валидные точки и отсутствие сетево-покрытых точек.
- Слайд 19 теперь показывает географическое распределение сетевых пропусков и контроль двух независимых условий: сетевого покрытия и присоединения к BlocksNet.
- В приложении обновлён набор карт; логотип и график по 43 направлениям остаются прежними ресурсами v32.

## Важная коррекция
В прежнем `programming_delta_b1.png` подпись сводной полосы показывала 62,9% отрицательных, 26,6% нулевых и 10,5% положительных медиан. Это распределение ИЗО, а не программирования. Новая карта программирования пересчитана по `b1_81.csv`: 213 отрицательных (9,5%), 971 нулевая (43,2%), 1 062 положительных (47,3%). Для ИЗО 62,9% / 26,6% / 10,5% подтверждаются `b1_38.csv`.

## Пересборка
Из корня репозитория:
```bash
python presentation/map_sources/maps_b1_v24.py
python presentation/map_sources/build_direction_chart_v35.py
```
Нужны Python 3.10+, pandas и matplotlib. Маршрутизация не запускается; используются готовые CSV и геометрия, сохранённые в `map_sources`.

## Ограничения
- N — число уникальных опубликованных координат Navigator, а не число групп, свободных мест, детей или участников.
- Модальное состояние квартала — агрегат по жилым точкам; оно не означает однородность всего квартала.
- «Есть для обоих возрастов» не требует одной и той же координаты.
- Нулевая разница означает равное N13 и N7; это может быть 0–0 или равные положительные значения.
- Карта сетевого покрытия — диагностика привязки жилых точек к сети в пределах 250 м, а не показатель доступности.
- На картах нет подписей районов и водных объектов: проверенный слой для таких ориентиров в опубликованных входах отсутствует.
- Статическая проверка HTML и SVG выполнена; полноценный просмотр всей презентации в браузере не выполнен.
