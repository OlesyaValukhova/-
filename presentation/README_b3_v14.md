# Презентация v14

Актуальная версия `age_accessibility_b3_v14.html`: 20 слайдов, встроенные графики, карты и заметки. B1 — 43 направления, распределение из `results/conference-direction-comparison-20261111/b1-direction-summary.csv`; B3 — два направления, квартальная агрегация. Проценты на картах относятся к жилым точкам, цвета — к преобладающему состоянию квартала. B3 предварителен. Общая карта всех направлений не построена: для неё нужна проверенная привязка поадресных данных к кварталам, суммы направлений недопустимы из-за пересечений. Скачайте HTML и откройте в браузере.
