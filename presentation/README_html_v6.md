# Офлайн-презентация v6

`age_accessibility_v6.html` — автономная копия 20 слайдов презентации v6. Изображения и текст выступления встроены в файл, поэтому после скачивания интернет и соседние файлы не нужны. Откройте HTML в браузере. Слайды переключаются кнопками или клавишами стрелок; кнопка «Показать заметки» открывает черновик речи. Хронометраж и автоматическое переключение не включены.

HTML показывает слайды как изображения. Для редактирования объектов используйте `age_accessibility_maps_v6.pptx`. Исходная презентация агента в `master` и эта версия отличаются порядком и содержанием, см. `README_v6.md`.

Для повторной сборки: `node presentation/render_html_source.mjs ПУТЬ/age_accessibility_maps_v6.pptx html_build`, затем `python presentation/build_presentation_html.py html_build presentation/speaker_script_v6.md presentation/age_accessibility_v6.html`. Требуется `@oai/artifact-tool`; при желании код логики можно проверить скриптом `presentation/verify_html_logic.mjs` из корня проекта после генерации в `output/`.

Проверены наличие 20 встроенных PNG и логика переходов, границ и заметок в изолированной среде JavaScript. Визуальная проверка браузера не выполнена: запуск браузера в среде заблокирован. Внешний вид изображений слайдов проверялся при подготовке PPTX.
