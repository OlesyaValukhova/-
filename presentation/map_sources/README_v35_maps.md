# Карты B1 v35

В v35 квартальные карты заново построены в векторном SVG непосредственно из сохранённых таблиц B1 и геометрии BlocksNet. Повторная маршрутизация не выполнялась.

## Входы
- `b1_81.csv` — программирование.
- `b1_38.csv` — изобразительное искусство.
- `blocks_v22.json.gz.b64` — 3 330 кварталов BlocksNet, EPSG:32636.

Геометрия — сжатый GeoJSON. Генератор проверяет CRS, число кварталов, уникальность и совпадение ID, а также равенство `n_origins = n_valid + n_uncovered` по каждому кварталу.

## Выходы
- `assets_v35/programming_states_b1.svg`
- `assets_v35/art_states_b1.svg`
- `assets_v35/programming_delta_b1.svg`
- `assets_v35/art_delta_b1.svg`
- `assets_v35/network_coverage_b1.svg`

Все карты имеют одинаковые экстент, масштаб, проекцию, формат 16:9, белый фон и сдержанную палитру. Легенды показывают фактическое число кварталов в каждом классе.

## Содержание карт
- **Возрастные состояния:** модальный класс среди жилых точек квартала при `n_valid ≥ 3`; ничья, 1–2 валидные точки и отсутствие сетево-покрытых точек показаны отдельно.
- **Парная разница:** медиана по-точечной разницы `N13 − N7`; интервалы: меньше −2, от −2 до 0, 0, больше 0 до 2, больше 2. Малые выборки и отсутствие сетевого покрытия отделены от нулевой разницы.
- **Сетевое покрытие:** доля жилых точек квартала без привязки к пешеходной сети в пределах 250 м. В данных 3 265 кварталов имеют 0% непокрытых точек, один — 5,3%, 64 — 100%.

## Контроль знаменателей
Из 30 611 исходных жилых точек:
- 30 224 имеют сетевое покрытие, 387 — нет;
- 30 609 пространственно присоединены к кварталам, 2 — нет;
- 30 222 одновременно покрыты сетью и присоединены к кварталу — знаменатель квартальных показателей.

Два вида пропусков независимы. 387 непокрытых точек входят в пространственно присоединённые кварталы, но исключаются из сетевого знаменателя. Две покрытые точки не попали ни в один квартал. Ни одна группа не кодируется нулевой доступностью.

## Пересборка
Из корня репозитория:
```bash
python presentation/map_sources/maps_b1_v24.py
```
Нужны Python 3.10+, pandas и matplotlib (они используются и в прежних картографических скриптах). Генератор читает локальные входы относительно своего расположения, а не текущей рабочей директории; пишет SVG в `presentation/assets_v35/` и сводку в `presentation/map_sources/coverage_audit_v35.json`.

## Ограничения
N — число уникальных опубликованных координат Navigator, а не подтверждённые группы, места или участники. «Есть для обоих возрастов» означает хотя бы одну координату для каждого возрастного среза, не обязательно одну и ту же. Нулевая разница означает равные числа координат и может возникнуть при 0–0. Карта сетевого покрытия — контроль привязки жилых точек к сети, а не карта доступности занятий. На картах нет районных и гидрографических подписей: проверенный слой для них не включён во входные данные.
