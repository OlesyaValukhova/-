# Парное сравнение общегородского B3 для слайда 8

Исходный файл: `results/blocksnet-b3-citywide-20261111/full_observable/b3-by-origin.csv`, blob `db3141dfe09693868fea825fe43a5af7f5c392da` ветки master на момент расчёта. Сценарий: пешком и общественным транспортом, 30 минут, 5 минут ожидания на посадку; уникальные опубликованные координаты Navigator без суммирования направлений. Поля `age_7_N_venue_proxy_within_30min`, `age_13_N_venue_proxy_within_30min`.

Проверка: 30 611 уникальных origin_id; 30 224 покрытых сети, 387 неподключённых исключены. У покрытых пропусков возрастных значений нет. Парная разность N13 − N7: отрицательная 25 277 точек (83,6%), нулевая 3 332 (11,0%), положительная 1 615 (5,3%); округлённые доли не обязаны составлять ровно 100%. Равенство включает 1 464 точки, где оба значения равны нулю. Медиана разности −8 координат. Это доли жилых точек, не детей; данные об опубликованных координатах не подтверждают наличие мест и фактические поездки.

Для воспроизведения положить CSV под именем `b3_all_origins.csv` и файл `age_accessibility_b3_v20.html` под именем `accessibility_b3_v20.html` рядом со скриптом `add_b3_paired_v21.py`, затем выполнить `python add_b3_paired_v21.py`. Нужен pandas. Создаётся `accessibility_b3_v21.html`.

Квартальную карту по всем направлениям этот расчёт не строит: CSV не содержит геометрии или блока; доступный инструмент не передал исходный 31,7 МБ GeoJSON. Нужна проверенная привязка origin_id к кварталам по исходной геометрии; суммировать направления нельзя.
