# Дополнительные карты B1 к презентации v19

Три карты встроены в раскрываемый раздел под слайдами; существующие 20 слайдов v18 не изменены. Источник квартальных показателей: [age-profiles-blocks-b1-20261112-r2](https://github.com/OlesyaValukhova/-/tree/master/results/age-profiles-blocks-b1-20261112-r2), слой геометрии — кварталы BlocksNet с идентификатором `blocksnet_block_id`. Карты показывают 30 минут пешком, возрастные срезы 7 и 13 лет. Маршруты заново не рассчитывались.

`maps_b1_v19.py` строит изображения из `blocks.json` (GeoJSON кварталов в EPSG:32636 с полем `blocksnet_block_id`) и двух извлечений `b1_38.csv`, `b1_81.csv` из `age_profiles_by_block.csv` по `study_area_id`. Требуются pandas, matplotlib и соседний `make_research_maps.py`. Входной GeoJSON предварительно готовится из слоя квартальных геоданных с уникальными ID, а CSV — фильтрацией исходной таблицы. При несовпадении ID квартал показывается вместе с группой менее трёх валидных точек. Скрипт не скачивает исходные данные.

Доля справа рассчитана взвешиванием квартальных долей по числу валидных точек; знаменатель 30 222 точки, привязанные к кварталам. Вход содержит 30 611 точек, 387 без сетевого покрытия, две покрытые не присоединены к кварталам. Карта агрегирует данные точек и не утверждает, что весь квартал однороден. Цвет «нет координат» означает отсутствие найденного предложения модели, не отсутствие занятий в реальности.
