# Карты возрастной разницы для ИЗО — v28

Новая работа агента [white_maps_v6](https://github.com/OlesyaValukhova/-/blob/codex/presentation-theory-additions-20261112/presentation/age_accessibility_white_maps_v6.html) предложила сопоставить доступность ИЗО и возрастную разницу. В v28 сохранены исходные 20 слайдов: на слайде 13 добавлена кнопка, переключающая прежнюю карту состояний на карту разницы, с графиком рядом. Кнопка B1/B3 переключает сценарий для обоих видов карты.

Показатель — медиана по жилым точкам внутри квартала парной разницы N13 − N7 достижимых за 30 минут уникальных опубликованных координат Navigator. Это не разность двух квартальных медиан и не число детей, занятий, свободных мест или поездок. Ноль включает отсутствие координат для обоих возрастов. В легенде отдельно показаны 1–2 валидные точки и отсутствие результата / несовпадение геометрии.

Данные: `b1_38.csv` (blob `84c0ab83efbf45641effc82991ad8568cb660d16`) в этой папке и [B3 area_38_art_blocks_b3.csv](https://github.com/OlesyaValukhova/-/blob/master/results/age-profiles-blocks-b3-20261112/focus-directions/area_38_art_blocks_b3.csv) (blob `382efd074ab35791aab1d190fdce1ecfd6c603ec`); геометрия `blocks_v22.json.gz.b64`. Для карты B1 все идентификаторы совпали; для B3 три квартальных ID отсутствуют в геометрии, и три геометрии не имеют совпадения. Кварталы без совпадения показаны отдельно.

График на карте: B1 — 2 246 кварталов с ≥3 валидными точками; отрицательная медиана 1 413 (62,9%), нулевая 597 (26,6%), положительная 236 (10,5%). B3 — 2 243 квартала; отрицательная 1 640 (73,1%), нулевая 472 (21,0%), положительная 131 (5,8%). Это доли кварталов в указанной подвыборке, не доли жилых точек или детей. Не следует делать выводы о причинах различий или сравнивать эти доли как показатель населения.

Для воспроизведения положить рядом `map_art_delta_v28.py`, `make_research_maps.py`, `blocks_v22.json.gz.b64`, `b1_38.csv` и таблицу B3 под именем `data0.csv`, затем запустить `python map_art_delta_v28.py`. Необходимы pandas и matplotlib. Исходные карты проверены визуально отдельно; логика переключений проверена программно, полная визуальная проверка HTML в браузере остаётся необходимой.
