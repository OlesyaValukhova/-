# Подготовка общей карты возрастной разницы B3

Этот скрипт готовит таблицу и геометрию для ранее запрошенной карты: **все наблюдаемые координаты вместе**, без суммирования пересекающихся направлений. Для каждой подключённой жилой точки рассчитывается парная разница количества достижимых координат `N13 − N7`, затем в квартале берётся медиана этих разностей. Это не разность двух медиан.

Нужные входы:

1. [Полные точечные результаты B3 с геометрией](https://github.com/OlesyaValukhova/-/blob/master/results/blocksnet-b3-citywide-20261111/full_observable/b3-by-origin.geojson), blob `42d7de185c02c63bbcc4f1fd065b15dabb85f078`.
2. [Тот же точечный расчёт B3 в CSV](https://github.com/OlesyaValukhova/-/blob/master/results/blocksnet-b3-citywide-20261111/full_observable/b3-by-origin.csv), blob `db3141dfe09693868fea825fe43a5af7f5c392da`.
3. Исходные кварталы BlocksNet `blocks_cleaned.geojson`: именно полный файл, который использовал агент; его путь указан в [исходном скрипте агрегации](https://github.com/OlesyaValukhova/-/blob/master/src/aggregate_b3_age_profiles_blocks.py). Он не опубликован в репозитории.
4. [Контрольная квартальная таблица B3 для ИЗО](https://github.com/OlesyaValukhova/-/blob/master/results/age-profiles-blocks-b3-20261112/focus-directions/area_38_art_blocks_b3.csv), blob `382efd074ab35791aab1d190fdce1ecfd6c603ec`. Она нужна **только для проверки привязки и чисел**, а не для расчёта общего предложения.

В Python с pandas, geopandas, shapely 2 и пространственным индексом:

```bash
python aggregate_citywide_b3_v31.py \
  --origin-geojson /path/to/b3-by-origin.geojson \
  --reference-origins /path/to/b3-by-origin.csv \
  --blocks /path/to/blocks_cleaned.geojson \
  --reference-b3 /path/to/area_38_art_blocks_b3.csv \
  --out /path/to/new_empty_output
```

Скрипт проверяет совпадение идентификаторов и возрастных показателей GeoJSON с CSV; восстанавливает устойчивые ID кварталов тем же способом и тем же предикатом `within`, что использованы агентом. До записи результатов он требует 30 611 уникальных точек, 30 224 покрытых, 30 609 привязанных, 9 567 кварталов после удаления совпадающей геометрии и совпадения ID и чисел точек с контрольной таблицей для всех 3 330 кварталов. Любое расхождение останавливает работу. Значение с отсутствующим сетевым покрытием не считается нулём.

При успешной проверке создаются CSV с `n_origins`, `n_valid`, `n_uncovered`, `n_unknown`, `median_delta_N`, геоданные кварталов и JSON с контролем охвата. Данные не измеряют посещение, наличие мест, безопасность или самостоятельность детей.

**Статус:** протестирована логика парной медианы, настоящего нуля, пропуска и отсутствия покрытия на синтетических данных. Полный пространственный расчёт в текущей среде не выполнялся: инструмент GitHub не передал точечный GeoJSON размером около 31,7 МБ, а полный исходный файл кварталов отсутствует в репозитории. Поэтому таблица и карта результатов ещё не созданы; для реального запуска нужны перечисленные файлы и пространственные зависимости. Существующая презентация v30 и работа агента не изменены.
