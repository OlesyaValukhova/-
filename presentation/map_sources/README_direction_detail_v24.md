# Расшифровка графика по 43 направлениям — v24

Раскрываемая таблица под слайдом 11 сохраняет исходный график и расшифровывает столбцы слева направо. Источник: [b1-direction-summary.csv](https://github.com/OlesyaValukhova/-/blob/master/results/conference-direction-comparison-20261111/b1-direction-summary.csv), blob `529b7a5b18886f0e9b6e40c9b71d653ea0d2e572`. Все 43 строки и их порядок проверены по этому файлу.

Сценарий B1 — пешком, 30 минут, среди 30 224 жилых точек с сетевым покрытием. Доля с хотя бы одной опубликованной координатой равна 100% минус поле `age7_zero_pct_30min` или `age13_zero_pct_30min`; столбец «разница» равен доле для 13 лет минус доле для 7 лет в процентных пунктах. Значения отражают опубликованные координаты и возрастной допуск, а не долю детей, наличие мест или фактические поездки. Это поперечное сравнение возрастных срезов, не наблюдаемая динамика.

Скрипт `build_direction_detail_v24.py` формирует HTML-фрагмент из файла `direction_summary.csv`, который необходимо сохранить из указанного источника; нужен pandas. Открыть расшифровку можно под слайдом 11. Визуальная проверка в браузере остаётся необходимой.
