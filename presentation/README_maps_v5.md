# Карты для презентации НИР

Версия v5: три карты на слайдах 14, 15 и 18; прежняя версия v4 сохранена. Слайд 18 заменяет обзорный слайд о квартальных профилях, его заметки сохранены и дополнены методикой карты.

## Данные и смысл

Источник: `age_profiles_blocks.zip`, `age_profiles_blocks.gpkg`, слой `profiles`, 3 330 кварталов BlocksNet для каждого направления. Сценарий B1: 30 минут пешком по сети. Коды 81 и 38: программирование и изобразительное искусство. N — число уникальных опубликованных координат, доступных из жилой точки для указанного возраста. Это не число детей, групп или свободных мест. Отсутствие координаты в данных не доказывает отсутствия занятий.

Карта разности показывает медиану **парных** значений N13 − N7 среди валидных жилых точек каждого квартала, а не разность двух квартальных медиан. Положительные значения означают больше достижимых координат для 13 лет, отрицательные — для 7 лет. Серым отдельно показаны кварталы менее чем с тремя точками с сетевым покрытием. Из 2 246 кварталов с как минимум тремя валидными точками у всех есть рассчитанная медиана. Классы: <−2, [−2, 0), 0, (0, 2], >2. Это картографические интервалы, а не нормативные пороги.

## Воспроизведение

Нужны GDAL (`ogr2ogr`), Python и matplotlib. Из корня проекта: `python src/presentation_maps_b1.py ПУТЬ/age_profiles_blocks.gpkg presentation/maps`. Для сборки PPTX нужен пакет `@oai/artifact-tool` и исходный файл `itmo_age_accessibility_white_v2.pptx`: `node presentation/build_map_deck.mjs ПУТЬ/itmo_age_accessibility_white_v2.pptx presentation/maps ПУТЬ/выход.pptx`. Исходный PPTX и GeoPackage не включены в репозиторий этой ветки. Скрипт предназначен для указанного 20-слайдового источника, а не для произвольной презентации.

Визуально проверены новые картографические слайды; целостность PPTX и 22 слайда прошли автоматическую структурную проверку. 22 слайда отличаются от исходного ориентира из 20: для формата с жёстким ограничением нужно дополнительно сократить сценарий и проверить хронометраж. Проверки в установленном Microsoft PowerPoint не выполнялось.
