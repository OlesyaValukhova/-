# Актуальная HTML-презентация

`age_accessibility_b3_v11.html` — самостоятельная версия: 20 слайдов, заметки, карты и изображения встроены. Скачайте файл и откройте в браузере. Карты используют предварительный сценарий B3; на отдельных графиках указан B1. PPTX и прежний HTML v6 не являются источником текущей версии. Три идентификатора кварталов не совпали с имеющейся геометрией и не окрашены по B3.
