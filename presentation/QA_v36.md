# QA презентации НИР v36

## Найденное расхождение

В `coverage_audit_v35.json` четыре значения `weighted_access_pct` не воспроизводились из файлов `b1_81.csv` и `b1_38.csv`. При этом:
- скрипт `maps_b1_v24.py` содержит контрольные значения 46,4132 / 63,2486 для программирования и 85,4047 / 80,9841 для ИЗО;
- отчёт B1 в master приводит те же доли с округлением до двух знаков;
- прямое взвешивание долей по `n_valid` из обеих CSV даёт эти же значения.

Поэтому в v36 создана отдельная исправленная сводка; файл v35 не перезаписывался.

## Сверка по исходным CSV

| Направление | 7 лет, CSV | 13 лет, CSV | Контроль B1 |
|---|---:|---:|---|
| Программирование | 46,4132% | 63,2486% | Совпадает |
| ИЗО | 85,4047% | 80,9841% | Совпадает |

Расчёт: для 7 лет `(both_pct + only_7_pct)`, для 13 лет `(both_pct + only_13_pct)`; каждое квартальное значение взвешено по `n_valid`, сумма делится на 30 222 валидные точки.

## Остальные проверки

По обоим CSV:
- 3 330 строк и уникальных ID кварталов;
- 30 609 присоединённых жилых точек;
- 30 222 валидные сетево-покрытые точки;
- 387 сетево-непокрытых точек;
- суммы `n_origins = n_valid + n_uncovered` соблюдаются по каждому кварталу;
- распределения модальных состояний совпадают с v35;
- интервалы медианы парной разницы и знаки совпадают с v35;
- классы сетевого покрытия совпадают с v35.

График по 43 направлениям независимо перепроверен: 43 уникальных направления, 30 224 сетево-покрытые точки на направление, 24 положительные и 19 отрицательных разниц, диапазон от −16,98 до +47,14 п.п. Медианы по 43 направлениям для 15/20/30 минут совпадают с отчётом B1.
