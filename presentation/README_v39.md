# Презентация НИР v39

Основа — v38, ветка `codex/presentation-direction-distributions-v38`. Работа агента сохранена; новая итерация находится в отдельной ветке.

## Содержательные изменения

- Слайд 15 заменён общей двухпанельной картой парной разницы B1 для программирования и ИЗО.
- Обе панели построены из одной геометрии BlocksNet и двух квартальных CSV, имеют общий экстент, одинаковые интервалы и одну легенду.
- Убрано переключение между двумя отдельными картами: сравнение направлений видно одновременно.
- Добавлен PNG-превью для визуальной проверки; презентация использует SVG.
- Добавлен аудит атрибутов геометрии BlocksNet: он показывает, есть ли в источнике поля для районов/административных единиц, прежде чем добавлять подписи на карту.
- Слайды 11 и 16, а также их графики по 43 направлениям сохранены из v38.

## Методика

B1, пешком, 30 минут; 7 и 13 лет. Медиана сначала рассчитывается по парным различиям N13−N7 на жилых точках, затем агрегируется внутри существующего квартала BlocksNet. Кварталы с 1–2 валидными точками и без сетевого покрытия показаны отдельными классами. N — уникальные опубликованные координаты Navigator, не группы, свободные места или участники.

## Пересборка

```bash
python presentation/map_sources/build_b1_paired_delta_map_v39.py
python presentation/map_sources/verify_paired_delta_map_v39.py
```

Зависимости генератора: pandas и matplotlib; геометрия читается из `blocks_v22.json.gz.b64`, таблицы — из `b1_81.csv` и `b1_38.csv`.

## Ограничения

- Квартальная медиана не описывает каждый адрес внутри квартала.
- Карта не показывает фактические поездки, спрос, число групп или наличие мест.
- Географические подписи районов не добавляются автоматически: сначала нужно проверить административные поля в `geometry_inventory`.
- По-точечные B1-результаты и геометрия жилых точек не опубликованы, поэтому точечные карты не создаются.
- Визуальная проверка PNG-превью и HTML в браузере должна быть выполнена отдельно после успешной сборки.
