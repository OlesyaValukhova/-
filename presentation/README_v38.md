# Презентация НИР v38

Основа: v37 (codex/presentation-b1-denominator-v37); предыдущие версии не изменялись.
Сценарий: B1, пешком; 7 и 13 лет; 30 минут — основной порог, 15/20 минут — чувствительность.
Объём: 20 слайдов. Основные квартальные карты v35 сохранены; два аналитических графика на слайдах 11 и 16 построены заново из сводки B1 по 43 направлениям.

## Что изменено

- Слайд 11 заменён парной диаграммой (dumbbell): для каждого из 43 направлений одновременно видны доли жилых точек с хотя бы одной координатой для 7 и 13 лет, соединение показывает разницу. Направления отсортированы по Δ = доступность(13) − доступность(7).
- Слайд 16 заменён шестью boxplot: по 43 направлениям для каждого возраста и порога 15/20/30 минут показаны min–max, Q1–Q3 и медиана. Это сохраняет медианы прежней сводки, но не скрывает разброс между направлениями.
- Речь обновлена до v11: объясняет, как читать парные значения и распределение, не повторяя текст графиков.
- Белый фон, компактные заголовки и палитра v37 сохранены. Карты BlocksNet не менялись.

## Источник и расчёт

Вход: presentation/map_sources/b1-direction-summary.csv, 43 строки, 30 224 сетево-покрытые жилые точки на каждое направление.

Для направления и возраста: accessibility_pct = 100 − age*_zero_pct для соответствующего порога.
Для слайда 11: delta_pp = accessibility_13 − accessibility_7.
Для слайда 16: min, Q1, медиана, Q3, max по 43 значениям каждого возраста и порога. Квантили рассчитаны линейной интерполяцией при h=(n−1)*p.

## Пересборка

Запуск из корня репозитория:
    python presentation/map_sources/build_direction_charts_v38.py

Только стандартная библиотека Python. Скрипт проверяет число и уникальность направлений, знаменатель и диапазон процентов; сохраняет два SVG и direction_distribution_audit_v38.json.

## Ограничения

- 43 направления — набор направлений в опубликованной сводке B1, не взвешенная выборка всех занятий города.
- Медианы и квартили — распределения по направлениям, а не доли всех детей или всех жилых точек Петербурга.
- Координата Navigator — прокси наблюдаемого предложения; она не подтверждает место проведения группы, свободное место, запись или поездку.
- Эти два графика не являются картами и не добавляют географической локализации.
- Новые квартальные карты не строились: в текущей сессии геометрический blob BlocksNet возвращён GitHub-коннектором без содержимого. Существующие SVG-карты сохранены. По-точечные результаты B1 и геометрия жилых точек не опубликованы; псевдокарты из квартальных агрегатов не создавались.
