# Презентация НИР v34 — основной сценарий B1

## Файлы
- `age_accessibility_b3_v34.html` — основная HTML-презентация, 20 слайдов.
- `speaker_script_v9.md` — речь к той же последовательности слайдов.
- `QA_v34.md` — проверка данных, структуры и ограничений.
- `map_sources/joint_states_b1_v34.json` — сводка совместных возрастных состояний для слайда 14.
- `map_sources/verify_joint_states_b1_v34.py` — локальная проверка сводки по двум квартальным CSV.
- `map_sources/maps_b1_v23.py` — генератор квартальных карт B1; в этой версии добавлены проверки целостности геометрии и данных, уточнена легенда ничьей и добавлен экспорт парной разницы для ИЗО.

## Содержание v34
v34 оставляет в основной последовательности только B1: пешком, 30 минут. Транспортный сценарий B3 и анализ застройки не включены в 20 слайдов: они остаются отдельными дополнительными материалами исследования.

- Слайд 7 объясняет единый пеший сценарий и фиксирует, что меняется только возрастной фильтр.
- Слайд 8 показывает число уникальных координат с возрастно-допустимой карточкой в общем наблюдаемом слое: 1 406 для 7 лет и 959 для 13 лет. Наборы могут пересекаться.
- Слайды 12–13 показывают квартальные карты B1 для программирования и ИЗО.
- Слайд 14 показывает четыре совместных состояния для тех же двух направлений. Доли взвешены по числу валидных жилых точек кварталов; знаменатель — 30 222.
- Слайд 15 показывает квартальную медиану парной разницы N13 − N7 для программирования.
- Слайд 19 отдельно показывает сетевое покрытие и присоединение к BlocksNet.

## Карты и ресурсы
HTML использует локальную папку `assets_v32/`; при переносе презентации сохраняйте её рядом с HTML. Три основные карты в слайдах 12, 13 и 15 — существующие B1-изображения. На слайде 13 можно переключиться на существующую карту парной разницы ИЗО B1.

Карты визуально проверены отдельно. Они имеют белый фон, сопоставимый общегородской охват, масштабную линейку и сдержанную палитру. При этом у них нет подписей районов, водных объектов и полноценной административной подложки. Встроенные PNG не были заново отрендерены в этой итерации; точная воспроизводимость конкретных PNG по текущему генератору ещё требует проверки.

## Воспроизведение квартальных карт
В `map_sources/` находятся `maps_b1_v23.py`, `make_research_maps.py`, `blocks_v22.json.gz.b64`, `b1_38.csv` и `b1_81.csv`. При наличии Python, pandas и matplotlib:
```bash
python maps_b1_v23.py
```
Скрипт создаёт карты состояний программирования и ИЗО, а также парной разницы для обоих направлений. Перед заменой изображений в презентации нужно визуально проверить легенды, малые классы и масштаб.

Для проверки чисел слайда 14:
```bash
python verify_joint_states_b1_v34.py
```

## Ограничения
Результат описывает сетевую достижимость опубликованных возрастно-допустимых координат. Он не измеряет спрос, вместимость, свободные места, запись, цену, расписание, безопасность маршрута, самостоятельность детей, фактические поездки или сопровождение родителей. Отсутствие координаты в каталоге не доказывает отсутствие занятия.
