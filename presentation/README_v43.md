# Презентация НИР v43

v43 сохраняет проверенную картографическую и содержательную версию v42. Единственное изменение HTML — версия документа; карты, B1-данные, легенды, границы 18 районов OSM, текст слайдов и выводы не менялись.

## Исправление контроля речи

В v42 файл `browser_qa_v42.mjs` считал длину строк из `speaker_script_v13.md`, хотя презентация и актуальная речь уже использовали `speaker_script_v14.md`. Поэтому опубликованный отчёт v42 не подтверждал лимит 45 слов именно для v14.

В v43:
- браузерная проверка читает `speaker_script_v14.md`;
- проверяет заголовок версии v14;
- проверяет ровно 20 пронумерованных реплик с последовательностью 1–20;
- сохраняет SHA-256 файла речи и версию в `report.json`;
- повторно отрисовывает все 20 слайдов при 1440×900;
- проверяет загрузку изображений, alt-тексты, белый фон, переполнение и ошибки JavaScript/консоли.

## Карты и методика

Все шесть картографических выходов и исходные данные берутся без изменений из v42. Административные границы 18 районов OSM остаются только внешним географическим ориентиром; единица анализа — квартал BlocksNet.

B1: пешком, 30 минут, возрастные срезы 7 и 13 лет. N — уникальные опубликованные координаты Navigator с возрастно-допустимыми карточками, а не число программ, групп, мест или участников. Знаменатель 30 224 относится к анализу 43 направлений, 30 222 — к квартальным показателям.

## Запуск

GitHub Actions workflow: `.github/workflows/presentation-browser-qa-v43.yml`. Он запускает только браузерную проверку и не пересчитывает B1, не обновляет OSM и не меняет карты.

См. также `QA_v43.md` после завершения workflow.
