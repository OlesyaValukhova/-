# Сверка презентации v37 с актуальным заданием НИР

## Последняя инструкция

В репозитории `OlesyaValukhova/second_brain_for_nir` последняя методическая редакция — коммит [70b96cb от 12.11.2026](https://github.com/OlesyaValukhova/second_brain_for_nir/commit/70b96cb98885949ab678cf38051336b9ac675da8).

Она фиксирует:
- единица расчёта — исходная жилая точка Urban API;
- единица территориального анализа — существующий квартал BlocksNet;
- сначала парное сравнение возрастов на жилых точках, затем агрегация по кварталам;
- B1, пешком, возрастные срезы 7 и 13 лет; 30 минут — основной порог, 15/20 минут — чувствительность при наличии готовых данных;
- не использовать центроиды кварталов, регулярную сетку 500 × 500 м, B0/B2/B3, транспорт или кластеризацию в рамках этой задачи;
- не восстанавливать точечные карты из городских или квартальных агрегатов.

## Что доступно в GitHub

Доступны и проверяются:
- `presentation/map_sources/b1_81.csv` — квартальные показатели программирования;
- `presentation/map_sources/b1_38.csv` — квартальные показатели ИЗО;
- `presentation/map_sources/b1-direction-summary.csv` — 43 направления и пороги 10/15/20/30 минут;
- `results/age-profiles-blocks-b1-20261112-r2/REPORT.md` и `manifest.json` — отчёт и происхождение квартальной агрегации.

В master не обнаружены опубликованные по-точечные B1-таблицы с `origin_id`, парными `N7/N13` и геометрией жилых точек. Отчёт B1 прямо говорит, что точные геометрии и по-точечные значения остаются локальными и не публикуются в репозитории.

## Следствие для карт

Пять карт v35 — это квартальные карты по BlocksNet, построенные из сохранённых квартальных CSV и геометрии кварталов. Они не являются картами исходных жилых точек. Нельзя достоверно получить положение и значения отдельных жилых точек из квартальных медиан и долей.

Поэтому v37 не добавляет псевдоточечные карты и не меняет квартальные результаты. Для полного MVP по текущему заданию нужны исходные по-точечные результаты B1 с устойчивым `origin_id`, значениями `N7`, `N13`, возрастными классами/флагами покрытия и геометрией жилых точек с CRS. После получения этих входов можно выполнить парную проверку и построить точечные карты, затем повторить квартальную агрегацию.

## Дополнительное ограничение среды

Файл геометрии BlocksNet `blocks_v22.json.gz.b64` и четыре крупные SVG доступны в GitHub как blobs с SHA, но GitHub-коннектор возвращает для них пустое тело. Сетевой `git clone` из рабочей среды также недоступен. Поэтому повторный запуск генератора карт v24 и визуальная браузерная проверка в этой сессии невозможны. Наличие файлов подтверждается GitHub blob SHA; содержимое и рендеринг не перепроверены.
