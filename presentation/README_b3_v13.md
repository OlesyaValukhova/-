# HTML-презентация v13

Актуальная версия — `age_accessibility_b3_v13.html`; скачать и открыть в браузере. 20 слайдов по формату печа-куча, встроенные заметки и карты, источники доступны под презентацией. B3 предварителен. Тёмно-серым обозначены кварталы с менее чем тремя валидными точками и несовпавшей геометрией; серо-голубым — преобладающее состояние без доступной координаты. Прежние версии сохранены. PPTX не используется.
