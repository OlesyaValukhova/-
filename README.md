# Цифровой урбанизм: доступность дополнительного образования

Рабочий репозиторий научно-исследовательского проекта о пространственной
доступности предложений дополнительного образования для детей в Санкт-Петербурге.
Проект объединяет подготовку данных, сетевые расчёты, квартальную агрегацию и
проверяемые материалы для докладов.

> **Статус:** исследование в работе. Репозиторий содержит рабочие результаты и
> не является готовым программным пакетом или официальным реестром услуг.

## Что исследуется

В текущих сценариях сравнивается доступность опубликованных координат карточек
каталога для возрастов 7 и 13 лет. Расчёты и визуализации интерпретируются как
характеристика доступности наблюдаемых координат, а не как число мест, групп,
участников, спрос или безопасность маршрута.

Полный контекст, исследовательские вопросы, методика и журнал решений ведутся
в отдельном репозитории исследовательских заметок
[`second_brain_for_nir`](https://github.com/OlesyaValukhova/second_brain_for_nir).

## Структура

```text
src/            скрипты подготовки, расчётов и проверок
tests/          автоматические проверки (когда применимо)
data/           локальные входные и промежуточные данные
results/        результаты прогонов, отчёты и материалы докладов
docs/           техническая документация и соглашения репозитория
```

Подробнее о том, что хранится в Git, а что остаётся локальным, см. в
[`docs/REPOSITORY-ORGANIZATION.md`](docs/REPOSITORY-ORGANIZATION.md).

## Быстрый старт

Репозиторий рассчитан на Python 3.10+; отдельные скрипты также используют
геопространственные библиотеки и локальные источники данных.

```bash
git clone <адрес-репозитория>
cd nir-digital-urbanism
python -m venv .venv
```

Активируйте окружение и установите зависимости, необходимые для конкретного
сценария. Точный набор входных данных, команда запуска и ожидаемые артефакты
должны быть описаны в `README.md` соответствующего каталога `results/`.

## Данные и воспроизводимость

Крупные скачанные данные, временные таблицы, GIS-экспорты, ZIP-архивы и логи
не публикуются в Git по умолчанию. Для каждого воспроизводимого прогона должны
быть зафиксированы источник данных, дата, используемый скрипт и ограничения
интерпретации. Уже опубликованные результаты не следует считать заменой
первичных данных или независимой репликацией расчёта.

## Результаты и материалы

Проверяемые отчёты, карты и материалы докладов находятся в `results/`.
Например, материалы PechaKucha хранятся в
[`results/conference-pechakucha-20261112/`](results/conference-pechakucha-20261112/).

Технические по-точечные выгрузки, диагностические прогоны и устаревшие версии
не входят в активную структуру `results/`; их полный снимок сохранён тегом
`archive-results-2026-11-20`.

### Архив финальной презентации

Полная проверенная версия PechaKucha v46 сохранена неизменяемым Git-тегом
`presentation-pechakucha-2026-11-final`. Тег хранит HTML, исходники карт,
сценарий и результаты browser QA; он намеренно не поддерживается как рабочая
ветка, чтобы промежуточные версии презентации не смешивались с НИР.

## Работа с проектом

- Не добавляйте в Git виртуальные окружения, скачанные наборы данных, логи и
  тяжёлые промежуточные артефакты.
- Сохраняйте код, краткое описание прогона и компактные проверяемые результаты.
- Перед изменением исследовательских вопросов, гипотез или методики сверяйтесь
  с репозиторием исследовательских заметок и документацией в `docs/`.
- Для нового прогона используйте имя вида `<тема>-<ГГГГММДД>` и добавляйте
  `README.md` с происхождением данных и командой запуска.

## Лицензирование и цитирование

Лицензия и рекомендуемый формат цитирования будут добавлены после решения
автора о режиме публикации данных, кода и исследовательских материалов.
