# Организация репозитория

Этот файл описывает рабочее соглашение для репозитория `nir-digital-urbanism`.
Он не является исследовательской заметкой и не меняет методику или результаты.

## Что является источником истины

| Материал | Место | Git |
| --- | --- | --- |
| Код и тесты | `src/`, `tests/` | Да |
| Описание исследования и инструкции | `README.md`, `AGENTS.md`, `docs/` | Да |
| Заметки Obsidian | `Исследование/` | Да, если это намеренно выбранный рабочий архив |
| Итоговые, проверяемые материалы | `results/**/*.md`, `*.html`, `*.svg`, `*.png`, `*.jpg`, `*.pdf` | Да, после проверки |
| Исходные скачанные данные, временные таблицы, GeoPackage, ZIP и логи прогонов | `data/`, `results/` | Нет; локально или во внешнем архиве |
| Локальные инструменты и виртуальные окружения | `.tools/` | Нет |

Файлы, уже добавленные в Git ранее, продолжают отслеживаться даже если теперь
попадают под правило игнорирования. Их не следует удалять без отдельной
проверки истории и воспроизводимости.

## Как оформлять новый прогон

1. Помещайте входные данные в `data/<тема>-<YYYYMMDD>/`.
2. Сохраняйте вывод в `results/<эксперимент>-<YYYYMMDD>/`.
3. Добавляйте короткий `README.md`: цель прогона, команда/скрипт, источник
   данных, дата и какие итоговые файлы следует проверить.
4. После проверки добавляйте в Git только код, описание и компактные итоговые
   материалы из разрешённых форматов.

## Очередь на следующий этап уборки

- `nir-digital-urbanism — копия` — старая полная копия; сначала сверить с
  основной папкой, затем перенести в архив или удалить по подтверждению.
- `projects/nir-digital-urbanism/worktrees/` — шесть временных worktree для
  загрузочных веток B3; проверить, какие ветки уже объединены, и удалить
  только закрытые worktree через `git worktree remove`.
- Корневой `.git` (в папке «Проект по умолчанию») — пустой репозиторий без
  коммитов; удалить только после подтверждения, поскольку он не относится к
  исследованию.
- GitHub — выбрать одну главную ветку и сверить временные ветки `codex/*`
  прежде чем закрывать их.
